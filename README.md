# QSSA - Plataforma de Gestión de Calidad y Servicios

Sistema integral de gestión de servicios de calidad, normalización y evaluación de la conformidad para **QUALITY STANDARD SERVICES ASSOCIATION S.R.L. (QSSA Bolivia)**.

Incluye la matriz completa de 29 servicios de normalización, auditorías y certificaciones ISO, diagnóstico interactivo de conformidad, asistente virtual de orientación técnica y panel de contacto con sedes a nivel nacional e internacional.

## Características Principales

- **Catálogo de 29 Servicios Especializados:** Consultoría, diagnósticos, auditorías internas y capacitaciones en normas ISO 9001, ISO 14001, ISO 45001, ISO 17020, ISO 17025, ISO 28000 y Programa OEA para el Corredor Bioceánico.
- **Diagnóstico y Filtros Dinámicos:** Búsqueda rápida, categorización, filtrado por viabilidad sin equipos de medición propios, dificultad y prioridad comercial.
- **Asistente Técnico Integrado:** Motor de respuestas autónomo para orientar al cliente en la selección de normas, requisitos y servicios adecuados sin dependencias externas.
- **Exportación de Datos:** Descarga de la matriz de servicios en formato CSV compatible con Microsoft Excel.
- **Gestión de Contacto Multisede:** Directorio de oficinas (Oruro, La Paz, Santa Cruz, Cochabamba) con enlaces directos a WhatsApp y acceso al correo corporativo institucional.

## Ejecución Local

**Prerrequisitos:** Node.js (v18 o superior)

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar la aplicación en modo desarrollo:
   ```bash
   npm run dev
   ```

3. Abrir en el navegador:
   ```
   http://localhost:3000
   ```

## Compilación para Producción

```bash
npm run build
npm run start
```
